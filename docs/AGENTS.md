# Vingo Roll Studio - Development Notes

## Project Structure

This is a modern React + TanStack Start ecommerce application for Vingo Roll, a premium window treatments brand.

### Tech Stack

- **React 19** - Modern UI framework
- **TanStack Router** - Full-stack routing solution
- **TanStack Query** - Server state management
- **Tailwind CSS v4** - Utility-first styling with custom theme
- **Radix UI** - Accessible component primitives
- **Vite** - Fast bundler and dev server

### Key Features

- Modern styled components with glassmorphism effects
- Smooth animations and transitions throughout
- Custom themed scrollbars (light & dark modes)
- Full accessibility support with keyboard navigation
- Responsive design for all screen sizes
- Mock data for ecommerce catalog and services

### Development Workflow

All commits are automatically tracked and the project is ready for continuous development.
